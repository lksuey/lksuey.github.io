# Lucas S. Soares: portfolio

Static portfolio site in Portuguese, English and Polish. Published with GitHub Pages at https://lksuey.github.io.

## What is here

- `index.html`, `en.html`, `pl.html`: the three language versions. Copy for English and Polish is applied from `locale.js`.
- Case pages: Assina AI, Relatório Supers and Luzia Amélia, each in Portuguese and English. All data shown is synthetic or fictional.
- `projects.js`: the list of projects shown in the Projects section.
- `three-motion.bundle.js`: motion system (Three.js bundled, no CDN at runtime).

## Run locally

```
python -m http.server 4173
```

Then open http://localhost:4173.
